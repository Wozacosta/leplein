## What Went Well

### 1. API Discovery & Adaptation (Story 1-3)
The 2aaz.fr API had two distinct endpoints - list endpoint without prices, detail endpoint with prices. The team adapted quickly by implementing parallel fetching with a 5-request concurrency limit to prevent rate limiting.

### 2. Strong Test Foundation
Established comprehensive test coverage from the start:
- Hook tests (useStations, useLocalStorage)
- Utility tests (formatPrice, formatDistance)
- Component tests (FuelFilter, StationList, ErrorMessage)

### 3. Code Review Process
Adversarial code reviews caught real issues before shipping:
- Touch targets below 44px minimum
- SSR hydration mismatches
- Missing accessibility attributes (ARIA labels, button types)
- Unused imports and embedded components

### 4. Type Safety & API Alignment
Corrected TypeScript interfaces to match actual API responses:
- `shortName` (camelCase) instead of `short_name` (snake_case)
- `available: boolean` instead of `rupture: boolean`
- Optional fields properly typed

### 5. UX Polish
- French locale formatting ("1,72 €/L", "il y a 2h")
- 44px touch targets on all interactive elements
- Responsive design from 320px to desktop (2-column grid on lg:)
- Persistent user preferences (fuel type + sort order via localStorage)

## Challenges & Learnings

### API Structure Discovery
**Challenge:** Initial assumptions about API response structure were incorrect.  
**Learning:** Always test against actual API responses before finalizing types. Added curl-based API testing to development workflow.

### Next.js Export Constraints
**Challenge:** `export default` required by Next.js App Router conflicts with project rule "named exports only."  
**Learning:** Documented as architectural exception - layout.tsx and page.tsx require default exports per Next.js requirements.

### Hydration Safety
**Challenge:** useLocalStorage hook caused hydration mismatch between server and client.  
**Learning:** Use useEffect to read browser APIs after initial render, return initialValue until hydrated.
